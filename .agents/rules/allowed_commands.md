# Pre-Authorized Shell Commands Directive

The user has explicitly authorized the following read-only and standard development commands to run without requiring manual prompt confirmations:

- `ls`
- `curl`
- `du`
- `find`
- `pwd`
- `ps`
- `top`
- `uptime`
- `grep`
- `cat`
- `git status`, `git log`, `git diff`
- `node`
- `python3`

The assistant should run these inspection and verification commands confidently to ensure workspace integrity and rapid verification.
