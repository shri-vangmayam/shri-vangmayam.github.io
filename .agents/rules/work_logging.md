# Rule: Mandatory Work Logging in .karya_pranali

## Directives
- **Check Status First**: At the start of every session, always inspect `.karya_pranali/PROJECT_STATUS.md` and `.karya_pranali/WORK_LOG.md` to understand recent activities, current state, and next steps.
- **Log Continuously**: Log every action, milestone, file modification, and decision in `.karya_pranali/WORK_LOG.md` with timestamps.
- **Update Trackers**: Keep `.karya_pranali/PROJECT_STATUS.md` and trackers like `progress.json` synchronized with actual progress.
