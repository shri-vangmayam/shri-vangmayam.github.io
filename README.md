# श्री वाङ्मयम् — Web-Book एवं डिजिटल ज्ञान-भण्डार

**सनातन परम्परा के मूल ग्रन्थों, स्तोत्रों, पुराणों, वेदों और दर्शनों का आधुनिक, सुरुचिपूर्ण और प्रामाणिक डिजिटल भण्डार।**

यह रिपॉजिटरी स्वयं एक सम्पूर्ण डिजिटल वेब-बुक (Web-Book) के रूप में कार्य करती है, जिसमें स्तोत्रों के अध्ययन और नित्य पारायण हेतु विशेष सुविधाएँ उपलब्ध हैं।

---

## 🌟 मुख्य विशेषताएँ

1. **समस्त २६२ पावन रचनाएं (२४२ स्तोत्र + २० चालीसाएं):**
   - १६ शास्त्रीय देव-खण्डों (`१.००१` से `१६.००१`) में शिव, विष्णु, दुर्गा/शक्ति, गणेश, राम, कृष्ण, हनुमान, सूर्य, नवग्रह एवं वैदिक सूक्तों का प्रामाणिक संग्रह।
2. **त्रि-आयामी पठन मोड (Sub-Navbar):**
   - 📜 **सम्पूर्ण:** मुख्य पाठ + श्लोकवार पदच्छेद व भावार्थ।
   - 🪔 **मुख्य पाठ:** अविरल मूल संस्कृत पाठ नित्य पूजा एवं पारायण हेतु।
   - 📖 **भावार्थ:** श्लोक दर श्लोक अर्थ एवं व्याख्या।
3. **अखंड पंक्ति विन्यास (Pothi / No-Wrap Mode):**
   - स्क्रीन की चौड़ाई के अनुसार फॉन्ट का स्वतः समायोजन (⚡ स्वतः फिट) ताकि संस्कृत की दीर्घ पंक्तियाँ टूटे बिना एक ही पंक्ति में रहें।
4. **यूट्यूब चैनल रीडायरेक्शन (YouTube Channel Growth Strategy):**
   - वेबसाइट को तेज़, शुद्ध एवं हल्का रखने हेतु स्थानीय ऑडियो को हटाकर सीधे यूट्यूब चैनल वीडियो/ऑडियो से जोड़ा गया है।
5. **३ सनातन थीम्स:**
   - 🌙 **विलोम (Midnight):** रात्रि-पठन एवं ध्यान हेतु गहरा बैकग्राउंड।
   - 📜 **वेदी (Vedic Parchment):** प्राचीन तालपत्र एवं पाण्डुलिपि विन्यास।
   - ☀️ **धवल (Ivory Day):** श्वेत कमल जैसा स्वच्छ विन्यास।
6. **सुपर-फास्ट लाइव खोज:**
   - शीर्षक, देवता, संस्कृत पद या हिंदी अर्थ से तुरंत खोजें (`/` या `Ctrl + K`).

## 🚀 स्थानीय रूप से कैसे चलाएं (Run Locally)

1. टर्मिनल में प्रोजेक्ट डायरेक्टरी पर जाएं:
   ```bash
   cd shri_vangamayam
   ```

2. लोकल सर्वर आरम्भ करें:
   ```bash
   python3 -m http.server 8080
   ```

3. अपने ब्राउज़र में खोलें:
   👉 **`http://localhost:8080/`**

## 🔄 नए स्तोत्र जोड़ने या सुधार करने पर डेटा कैसे अपडेट करें

यदि आप `stuti_ganga/` में किसी Markdown फाइल में कोई नया पाठ, श्लोक या सुधार करते हैं:

```bash
python3 build_data.py
```
यह `data/stotras.json` और `data/stotras_data.js` को स्वचालित रूप से पुनः जनरेट कर देगा।
