## परिचय एवं महत्त्व

यह स्तुति “नमामि शम्भुं पुरुषं पुराणं” से आरम्भ होती है। इसमें शिव के सनातन, सर्वज्ञ, करुणामय, भक्तरक्षक और कल्याणकारी स्वरूप को बार-बार प्रणाम किया गया है। प्रत्येक पद की आवृत्ति “नमामि शर्वं शिरसा नमामि” समर्पण का भाव व्यक्त करती है। आरम्भ और समापन में “नमामि शम्भो” का गेय पद है।

> **पाठ-संबंधी टिप्पणी:** इस स्तुति का आरम्भिक श्लोक *ब्रह्मपुराण*, अध्याय १२३ में श्रीराम द्वारा की गई शम्भु-स्तुति के रूप में मिलता है। वहाँ प्रसंग है कि श्रीराम ने महेश्वर की विधिपूर्वक पूजा करके उनकी स्तुति की।

## मूल स्तोत्र पाठ

```
नमामि शम्भो, नमामि शम्भो।
नमामि शम्भो, नमामि शम्भो॥

नमामि शम्भुं पुरुषं पुराणं, नमामि सर्वज्ञमपारभावम्।
नमामि रुद्रं प्रभुमक्षयं तं, नमामि शर्वं शिरसा नमामि॥ १॥

नमामि देवं भवभीतिहारं, नमामि भास्वन्तमनन्तरूपम्।
नमामि भक्तिप्रियकल्पवृक्षं, नमामि शर्वं शिरसा नमामि॥ २॥

नमामि शिवं शिवमेधमानं, नमामि कान्तं गिरिजाशरीरम्।
नमामि कालं कालकालरूपं, नमामि शर्वं शिरसा नमामि॥ ३॥

नमामि सोमं सोमसुधाकराङ्गशेखरं, नमामि नाथं नगराजचापम्।
नमामि देवं नरकान्तकारं, नमामि शर्वं शिरसा नमामि॥ ४॥

नमामि योगं योगपीठस्थितं, नमामि देवं त्रिनेत्ररूपम्।
नमामि लिङ्गं सर्वपापहारं, नमामि शर्वं शिरसा नमामि॥ ५॥

नमामि भूलोकमनन्तरूपं, नमामि स्वर्गं सकलस्वरूपम्।
नमामि पातालग्रतप्रभावं, नमामि शर्वं शिरसा नमामि॥ ६॥

नमामि वेदं वेदरूपधरं, नमामि मन्त्रस्वरूपदेहम्।
नमामि यज्ञं यज्ञभूमिस्थितं, नमामि शर्वं शिरसा नमामि॥ ७॥

नमामि देवं भुक्तिमुक्तिप्रदं, नमामि नाथं नागेन्द्रहारम्।
नमामि रुद्रं सकलप्रभावं, नमामि शर्वं शिरसा नमामि॥ ८॥

नमामि देवं त्रिभुवननाथं, नमामि शुम्भादिदैत्यसंहारम्।
नमामि देवं सुरसङ्घवन्द्यं, नमामि शर्वं शिरसा नमामि॥ ९॥

नमामि लिङ्गं ब्रह्मविष्णुवन्द्यं, नमामि देवं भक्तसंरक्षकम्।
नमामि देवं भवसिन्धुतारं, नमामि शर्वं शिरसा नमामि॥ १०॥

नमामि देवं करुणासमुद्रं, नमामि भास्वन्तमनन्तकान्तिम्।
नमामि शर्वाणीपतिं प्रसन्नं, नमामि शर्वं शिरसा नमामि॥ ११॥

नमामि देवं सकलस्वरूपं, नमामि शिवं सर्वमङ्गलदातारम्।
नमामि शम्भुं सर्वलोकनाथं, नमामि शर्वं शिरसा नमामि॥ १२॥

नमामि शम्भो, नमामि शम्भो।
```

## संस्कृत श्लोक एवं उनके हिंदी भावार्थ

### आरम्भिक गेय पद

```
नमामि शम्भो, नमामि शम्भो।
नमामि शम्भो, नमामि शम्भो॥
```

**भावार्थ:** हे कल्याणकारी शम्भु, मैं आपको बार-बार प्रणाम करता हूँ।

### श्लोक १

```
नमामि शम्भुं पुरुषं पुराणं, नमामि सर्वज्ञमपारभावम्।
नमामि रुद्रं प्रभुमक्षयं तं, नमामि शर्वं शिरसा नमामि॥ १॥
```

**भावार्थ:** मैं आदि और सनातन पुरुष शम्भु को प्रणाम करता हूँ। वे सर्वज्ञ, असीम स्वरूप वाले और अविनाशी प्रभु रुद्र हैं। उन शर्व को मैं सिर झुकाकर नमस्कार करता हूँ।

### श्लोक २

```
नमामि देवं भवभीतिहारं, नमामि भास्वन्तमनन्तरूपम्।
नमामि भक्तिप्रियकल्पवृक्षं, नमामि शर्वं शिरसा नमामि॥ २॥
```

**भावार्थ:** संसार के भय को हरने वाले, प्रकाशमान और अनन्त रूपों वाले देव को प्रणाम है। भक्तों के प्रिय और उनकी अभिलाषाओं के लिए कल्पवृक्ष-सदृश शिव को मैं सिर झुकाकर नमस्कार करता हूँ।

### श्लोक ३

```
नमामि शिवं शिवमेधमानं, नमामि कान्तं गिरिजाशरीरम्।
नमामि कालं कालकालरूपं, नमामि शर्वं शिरसा नमामि॥ ३॥
```

**भावार्थ:** कल्याणमय शिव को प्रणाम है, जिनका सुन्दर स्वरूप गिरिजा से संयुक्त है। वे कालस्वरूप और काल के भी काल हैं। उन शर्व को मैं सिर झुकाकर नमस्कार करता हूँ।

### श्लोक ४

```
नमामि सोमं सोमसुधाकराङ्गशेखरं, नमामि नाथं नगराजचापम्।
नमामि देवं नरकान्तकारं, नमामि शर्वं शिरसा नमामि॥ ४॥
```

**भावार्थ:** सोम अर्थात् चन्द्रमा से सुशोभित मस्तक वाले, पर्वतराज को धनुष बनाने वाले और नरक के दुःखों का अन्त करने वाले प्रभु को प्रणाम है। उन शर्व के आगे मैं सिर झुकाता हूँ।

### श्लोक ५

```
नमामि योगं योगपीठस्थितं, नमामि देवं त्रिनेत्ररूपम्।
नमामि लिङ्गं सर्वपापहारं, नमामि शर्वं शिरसा नमामि॥ ५॥
```

**भावार्थ:** योगस्वरूप और योगपीठ पर विराजमान त्रिनेत्रधारी देव को प्रणाम है। सभी पापों को हरने वाले शिवलिङ्ग को नमस्कार है; उन शर्व के आगे मैं सिर झुकाता हूँ।

### श्लोक ६

```
नमामि भूलोकमनन्तरूपं, नमामि स्वर्गं सकलस्वरूपम्।
नमामि पातालग्रतप्रभावं, नमामि शर्वं शिरसा नमामि॥ ६॥
```

**भावार्थ:** अनन्त रूपों में प्रकट और भूलोक तथा स्वर्ग सहित सबके स्वरूप में विद्यमान शिव को प्रणाम है। पद का समग्र भाव पाताल तक उनकी व्यापक महिमा का वन्दन है; स्रोत के एक अस्पष्ट शब्द की टिप्पणी नीचे दी गई है।

### श्लोक ७

```
नमामि वेदं वेदरूपधरं, नमामि मन्त्रस्वरूपदेहम्।
नमामि यज्ञं यज्ञभूमिस्थितं, नमामि शर्वं शिरसा नमामि॥ ७॥
```

**भावार्थ:** वेदस्वरूप, मन्त्रों को अपने दिव्य स्वरूप में धारण करने वाले, यज्ञस्वरूप और यज्ञभूमि में उपस्थित शिव को प्रणाम है। उन शर्व को मैं सिर झुकाकर नमस्कार करता हूँ।

### श्लोक ८

```
नमामि देवं भुक्तिमुक्तिप्रदं, नमामि नाथं नागेन्द्रहारम्।
नमामि रुद्रं सकलप्रभावं, नमामि शर्वं शिरसा नमामि॥ ८॥
```

**भावार्थ:** सांसारिक सुख और मुक्ति देने वाले, सर्पराज को हार के रूप में धारण करने वाले तथा समस्त सामर्थ्य से सम्पन्न रुद्र को प्रणाम है। उन शर्व के आगे मैं सिर झुकाता हूँ।

### श्लोक ९

```
नमामि देवं त्रिभुवननाथं, नमामि शुम्भादिदैत्यसंहारम्।
नमामि देवं सुरसङ्घवन्द्यं, नमामि शर्वं शिरसा नमामि॥ ९॥
```

**भावार्थ:** तीनों लोकों के स्वामी, स्रोत-पद में शुम्भ आदि दैत्यों के संहारक कहे गए और देवगणों से वन्दित प्रभु को प्रणाम है। उन शर्व को मैं सिर झुकाकर नमस्कार करता हूँ।

### श्लोक १०

```
नमामि लिङ्गं ब्रह्मविष्णुवन्द्यं, नमामि देवं भक्तसंरक्षकम्।
नमामि देवं भवसिन्धुतारं, नमामि शर्वं शिरसा नमामि॥ १०॥
```

**भावार्थ:** ब्रह्मा और विष्णु से वन्दित शिवलिङ्ग को प्रणाम है। भक्तों की रक्षा करने वाले और संसार-सागर से पार उतारने वाले देव को मैं सिर झुकाकर नमस्कार करता हूँ।

### श्लोक ११

```
नमामि देवं करुणासमुद्रं, नमामि भास्वन्तमनन्तकान्तिम्।
नमामि शर्वाणीपतिं प्रसन्नं, नमामि शर्वं शिरसा नमामि॥ ११॥
```

**भावार्थ:** करुणा के समुद्र, प्रकाशमान, अनन्त कान्ति से सम्पन्न तथा शर्वाणी अर्थात् पार्वती के प्रसन्नचित्त पति शिव को प्रणाम है। उन शर्व के आगे मैं सिर झुकाता हूँ।

### श्लोक १२

```
नमामि देवं सकलस्वरूपं, नमामि शिवं सर्वमङ्गलदातारम्।
नमामि शम्भुं सर्वलोकनाथं, नमामि शर्वं शिरसा नमामि॥ १२॥
```

**भावार्थ:** समस्त रूपों में विद्यमान, सभी प्रकार का मंगल देने वाले और सारे लोकों के स्वामी शम्भु को प्रणाम है। उन शर्व को मैं सिर झुकाकर नमस्कार करता हूँ।

### समापन

```
नमामि शम्भो, नमामि शम्भो।
```

**भावार्थ:** हे शम्भु, आपको पुनः प्रणाम है।
